WebUSB Diagnostics — AEC USB-TC

What can Chrome actually see?

If the reader will not connect, these checks narrow down where it is being lost — the filter, Chrome's USB backend, or the device itself. The USB-TC reports idVendor 0xAECB, idProduct 0x6600. 

Ready.

Pick the AEC USB-TC in the chooser if it appears. The product string differs between models — Time Code Reader on LTC-only units, Time Code and L21 Data Reader on video-capable ones.

An empty chooser is usually normal. Once an origin has been granted a device, Chrome stops offering it; use List already-granted to confirm. If “accept all devices” also shows nothing, the device is not reaching Chrome's USB backend at all — replug it, and prefer a direct port over a hub.
